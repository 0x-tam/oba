## 3D reconstruction opportunities (NOT original author models)

No source 3D model files are supplied. All are PDFs containing drawings, diagrams, renders and photos. Any web model would be a new, simplified interpretive reconstruction and must be labelled accordingly; avoid implying it is the original design model or fabrication documentation. These are especially well-supported:
1. Thing / Thing Flatpack: Omar pp37,39 and Amara pp28,29 provide multiple views, clear five-sided geometry and assembly diagrams. Best for an interactive object study with rotate, explode/assemble, and configuration changes. Dimensions are not reliably legible/provided, so proportions are approximate.
2. Landship: Omar pp28–29 show repeated frames, transformation sequence, section and perspectives. Best for an abstract frame-rotation model demonstrating how repeated square ribs generate the cabin form. Need not reproduce furniture or terrain exactly.
3. BIA: Omar pp34–35 explicitly provide exploded column, beam, capital, skylight and combination diagrams. Strongest architectural systems explorer: one structural unit → combination of units → expandable roof field. Approximate geometry with explanatory labels grounded in the page text.
4. Lebanese Concept House: Omar pp8–9 and Amara p23 show nodes, stems and branches from multiple angles. A simplified modular display kit with alternative arrangements is faithful to stated concept.
5. Playnook: Omar pp42–43 provide built/formal views and usage illustrations. Useful interactive fold/configuration study, but exact cut/fold pattern cannot be fully recovered; do not claim fabrication-ready geometry.
6. Artist’s Studio Balcony: Omar pp12–13 grid render and elevations support a modular lattice with removable functional zones. A schematic grid study is reasonable.
7. RDP5: Omar pp22–23 plan and colored configuration diagrams support a schematic top-down interactive plan where screens open/close. This may be more faithful and useful than inventing a fully furnished 3D scene.

For the website, prioritize one carefully made BIA modular structural model and one Thing object study. Both communicate Omar’s recurring interest in modularity and user agency; no need to add generic 3D to every project. Optional hand gesture controls can manipulate model rotation/zoom only after a clear user-initiated camera opt-in, with touch/mouse controls always present. Gesture interface is a website feature and not part of the documented architectural projects. Explain camera use concisely; local processing is preferred if implementation supports it.
